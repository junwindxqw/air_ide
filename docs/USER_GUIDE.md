# Air IDE 用户文档（v0.2.0）

> 定位：给「AI 写代码、人来审阅」的工作流 —— 读代码、看 Git Diff、跑 Git 操作。
> 平台：Windows 10 2004（build 19041）/ Windows 11，仅 x64。

## 安装

1. 从 GitHub Releases 下载安装包：
   - 最新版：<https://github.com/junwindxqw/air_ide/releases/latest>
   - 0.2.0：<https://github.com/junwindxqw/air_ide/releases/tag/v0.2.0>
2. **安装版**：双击 `Air.IDE_<版本>_x64-setup.exe`。安装范围为「当前用户」，
   不需要管理员权限；升级安装会保留 `%APPDATA%\AirIDE` 下的设置、会话与草稿。
3. **便携版**：下载 `Air.IDE_<版本>_x64-portable.zip`，解压后双击 `Air IDE.exe`。
   不写注册表、不建快捷方式、不注册卸载项；但配置/会话/日志仍写入
   `%APPDATA%\AirIDE` 与 `%LOCALAPPDATA%\AirIDE`（与安装版共用）。
   升级需退出后解压新版本覆盖 exe。
4. 未做 Authenticode 代码签名：若 SmartScreen 拦截，点「更多信息 → 仍要运行」。
5. 安装包会在需要时联网获取 WebView2 Runtime；便携版不会自动安装 WebView2，
   缺失时请先手动安装 Microsoft Edge WebView2 Runtime。
6. 卸载：Windows「设置 → 应用 → 已安装的应用 → Air IDE」。

系统低于 Windows 10 2004 时，启动会直接提示版本不足并退出，不会进入界面。

## 首次启动

首次启动且没有历史工作区时，显示欢迎页和 3 步引导：

1. **打开项目**：点「打开文件夹…」选择一个目录作为工作区；也可以把文件夹拖入窗口。
   之后可从「最近项目」重新打开。
2. **快捷键**：展示命令面板与常用键位（完整列表见下方）。
3. **语言服务器**：实时探测本机已安装的服务器。未安装的会列出安装提示；
   PHP 服务器（PHPantom）可直接点「一键下载」。下载失败会显示原因，
   也可以手动下载后放入 `%LOCALAPPDATA%\AirIDE\servers\` 再点「重新检测」。

点「跳过引导」或完成最后一步后，引导不再自动出现（标记保存在本地）。
下次启动会恢复上次的工作区与打开的标签页；没有工作区时仍会显示欢迎页，
但不再显示引导。

## 首次配置

设置窗口：`Ctrl+Alt+S`。保存后写入 `%APPDATA%\AirIDE\settings.json`，
并在启动时加载、应用到界面与编辑器。当前生效情况：

| 设置组 | 启动生效 |
|---|---|
| 编辑器：字号、行高、行号、当前行高亮、失焦保存、大文件/只读阈值 | 生效（保存后立即刷新，重启后保留） |
| 外观：主题（跟随系统 / Darcula Dark / IntelliJ Light） | 生效（启动与保存时按系统深浅色解析） |
| 系统：自动更新、Defender 提示 | 生效（控制启动静默检查与提示显示） |
| 编辑器：文件树自动定位 | 仅保存，尚未接入 |
| Git 组：exe 路径、默认 sign-off、忽略空白、status 节流、默认双栏 | 仅保存，尚未接入（需在对应界面手动切换） |
| 系统：单实例 | 仅保存；应用始终以单实例运行 |

- **Git 身份**：首次提交时会弹出内联表单，填写 `user.name` / `user.email`，
  可选「仅此仓库」或「全局」。

## 打开与审阅

- **快速打开**：`Ctrl+Shift+N`，空输入时列出前 20 个文件（按文件列表顺序，
  不是真实「最近打开」记录）；输入后做模糊匹配。
- **大文件降级**（阈值可在设置中调整，默认如下）：
  - 超过 **2MB**：关闭语言服务器与代码折叠，保留高亮/搜索；
  - 超过 **10MB**：只读模式，关闭编辑与 LSP，避免卡顿与误改。
- **看改动**：右侧 Git 工具窗（`Alt+9`）按「冲突 / 未暂存 / 未跟踪 / 已暂存」
  分组，双击任一条目打开 Diff。
- **启动参数**：第一个命令行参数若是已存在的文件路径，会直接打开该文件。
- **拖入窗口**：把文件或文件夹拖进窗口即可打开。

## Diff 审阅工作流

- **双栏视图**：左本地（HEAD）、右工作区；同步滚动。
- **hunk 操作**：工具栏 `» 暂存` / `« 取消` / `✕ 丢弃`（作用于当前 hunk）。
  - 丢弃只影响工作区且不可撤销，执行前会确认。
  - apply 失败时不修改任何内容，会提示失败原因（git 原文）。
- **词级高亮**：同一行内的变更词会加深底色。
- **忽略空白差异**：工具栏 `-w`；PHP 项目格式化后的 diff 靠它归零。
- **折叠上下文**：工具栏「折叠」把未变更的上下文行收起。
- **已读进度**：工具栏显示 `已读 x / y`，浏览过的 hunk 自动标记（仅本次会话）。

## Git 写入

- **复选框**：Changes 列表的复选框即 stage/unstage（勾选 = `git add`）。
- **提交**：message 支持多行；`↑`/`↓` 复用最近提交信息；amend 与 sign-off
  是复选框。提交失败时展示 git 原文。
- **撤销上次提交**：`reset --soft HEAD~1`，改动保留在暂存区（会确认）。
- **分支**：点 Git 工具窗顶部分支名 → 切换/新建/删除；fetch/pull/push
  在同一菜单。
- **Git 命令条**（`Ctrl+Alt+G`）：跑任意 git 命令（如 `rebase --abort`、`stash`），
  流式输出不截断。为安全起见禁用 `clean`、`gc`、`prune`、`filter-branch`、
  `update-ref`、`symbolic-ref`。
- **Git 身份未配置**：首次提交会弹内联表单（user.name / user.email），
  可选「仅此仓库」或「全局」。

## Git 冲突解决

- 入口：Git 工具窗「冲突」分组中双击文件（或点条目的解决按钮）打开冲突解决视图。
- 每个冲突块可选：
  - **采用当前（本地）**、**采用传入（远端）**、**两者保留**；
  - 支持「全部采用当前 / 全部采用传入 / 全部两者保留」一键应用。
- 结果区（实时预览）可直接手动编辑；编辑后显示「已手动编辑结果」，可点「还原为自动结果」。
  文件超过 512KB 时结果区只读，只能逐块选择。
- 保存前置校验：仍有未选择的冲突块、异常的 `<<<<<<< / ======= / >>>>>>>`
  标记结构、或结果中残留冲突标记时，禁止保存并给出原因。
- 提供「保存」与「**保存并暂存**」；保存写盘成功后再执行 `git add`，
  `git add` 失败会提示「文件已保存，但 git add 失败」。
- 保存成功后条目显示已解决标记；`Esc` 关闭视图。

## 语言智能

- **懒启动**：首次打开某语言文件时才启动对应语言服务器，不拖慢启动。
- **未安装服务器**：编辑器自动降级为语法模式（语法高亮、折叠仍可用）。
  「语言服务器管理」面板会列出安装提示；未安装的语言不会启动进程。
- **PHP 一键下载**：欢迎页引导或命令面板搜「语言服务器管理」→ PHPantom
  「一键下载」。装到 `%LOCALAPPDATA%\AirIDE\servers\phpantom\`；
  下载源不可用或校验/解压失败时会显示具体原因。
- **其他语言**：按面板里的安装提示手动安装，装好后重新打开
  「语言服务器管理」（打开时会重新探测）或点引导里的「重新检测」。
  常见安装方式（仅供参考，以各项目官方文档为准）：

  | 语言 | 服务器 | 常见安装方式 |
  |---|---|---|
  | Go | gopls | `go install golang.org/x/tools/gopls@latest` |
  | Python | basedpyright | `pip install basedpyright` |
  | Rust | rust-analyzer | `rustup component add rust-analyzer` |
  | TS / JS | typescript-language-server | `npm i -g typescript-language-server typescript` |
  | C / C++ | clangd | 安装 LLVM 工具链（含 clangd） |
  | JSON / YAML / HTML / CSS / Markdown | vscode-langservers-extracted | `npm i -g vscode-langservers-extracted` |

  探测顺序：`PATH` → 常见目录（`~\.cargo\bin`、`~\go\bin`、`%APPDATA%\npm`）
  → `%LOCALAPPDATA%\AirIDE\servers\`。
- **安装结果通知**：LSP 安装成功/失败会发系统通知；系统通知不可用时降级为应用内提示。

## 文件与编码

- **编码**：状态栏点编码名（UTF-8 / GB18030 / UTF-16 LE / UTF-16 BE / Latin-1）→
  「转换并保存」：内容不变、按新编码写回字节。
  「重新解释」（按指定编码重读）当前不可用（界面中已置灰）：后端读取时只做自动编码探测。
  需要按指定编码重读时，请先在外部工具中转码。
- **行尾**：状态栏点 `CRLF` / `LF` 切换，选择后立即按新行尾写回磁盘；
  `Mixed` 表示文件混用，保存时统一归一为 LF。
- **外部修改**：AI 工具改文件后——干净 tab 自动重载；有未保存改动时弹三选一横幅
  （重新加载 / 保留我的 / 对比差异），**不会静默覆盖**。
  「对比差异」会打开该文件的 Git Diff（工作区 vs HEAD）；文件不在工作区、
  未跟踪或无改动时会提示原因并保留横幅。

## Windows 集成

设置 →「系统」区块（Windows 集成开关也在此）：

- **系统集成开关**（仅 Windows）：手动开启后写入当前用户注册表（HKCU）——
  资源管理器右键文件夹可出现「用 Air IDE 打开」，文件关联只加入「打开方式」候选，
  不抢占默认程序。启动时不会自动注册；可随时关闭，写入失败会显示原因。
- **跳转列表**：打开项目后，最近项目会同步到任务栏右键跳转列表
  （依赖 Windows 任务栏注册；便携版尚未实机验证，需确认）。
- **任务栏进度**：耗时的 Git 操作、语言服务器安装等长任务在任务栏显示进度，
  短暂任务不闪烁。
- **通知**：LSP 安装结果、上次崩溃记录会通过系统通知提示；系统通知不可用时
  回退为应用内提示。
- **Defender 提示**：项目文件较多且实时防护开启时，状态栏上方会提示可将项目目录
  加入排除项（一键执行 `Add-MpPreference -ExclusionPath`，可「不再提示」，
  也可在设置中关闭该类提示）。
- **单实例**：再次启动会复用已有窗口并将其前置（当前固定开启）。

## 应用内更新

设置 →「更新」：

- 显示当前版本；
- **启动时静默检查**（默认开启，不自动安装，失败不弹窗、不阻塞启动）；
- 「检查更新」手动检查；发现新版本后点「下载并安装」，显示下载进度；
- 下载完成后校验 Minisign 签名，通过后以 passive 模式运行 NSIS 安装器，
  应用退出并由安装器重启；
- 失败按网络 / 签名 / 平台 / 环境分类，显示原始错误与处理建议；
- 更新源：<https://github.com/junwindxqw/air_ide/releases/latest/download/latest.json>，
  需要能访问 GitHub；
- **便携版不自动更新**：请从 Releases 手动下载新 zip 覆盖 exe。

## 故障排查

| 问题 | 处理 |
|---|---|
| 启动提示需要 Windows 10 2004 | 系统版本过低（需 build ≥ 19041），需升级系统 |
| 首次运行被 SmartScreen 拦截 | 未做 Authenticode 签名：点「更多信息 → 仍要运行」 |
| 启动白屏 / 提示 WebView2 | 安装 Microsoft Edge WebView2 Runtime 后重试（便携版不会自动安装） |
| 文件打不开（深层目录） | 尝试开启系统长路径：注册表 `LongPathsEnabled=1`，重启后再试 |
| 大项目首次 status 慢 | Defender 实时扫描所致；可按提示把项目目录加入排除项 |
| Git 相关功能不可用 | 需安装 Git for Windows ≥ 2.30 并在 `PATH` 中，安装后重启应用 |
| 语言服务器没反应 | `Ctrl+Shift+A` → 「语言服务器管理」查看安装/状态；停止后再打开文件重试 |
| 冲突无法保存 | 检查是否还有未选择的冲突块、异常标记结构或残留 `<<<<<<<` 标记 |
| 检查更新失败 / 404 | 检查网络或代理能否访问 GitHub；也可到 Releases 手动下载 |
| 更新安装后未重启 | passive 安装会退出应用并由安装器重启；若被拦截，请手动运行安装包 |
| 便携版想升级 | 退出后解压新版本 zip 覆盖 exe（便携版无应用内更新） |
| 崩溃 / 界面错误 | 日志在 `%LOCALAPPDATA%\AirIDE\logs\`；界面错误可点「重新加载」 |

## 已知限制（0.2.0）

- 未做 Authenticode 代码签名：首次安装/运行可能触发 SmartScreen；企业策略可能拦截。
  更新链路的 Minisign 验签是强制的，但不改变安装包的发布者身份。
- 便携版没有应用内更新，且与安装版共用数据目录；若在便携版触发更新，可能安装成 NSIS 版。
- 应用内更新与 WebView2 安装需要联网；无法访问 GitHub 时只能手动下载。
- 仅 x64，不支持 ARM64。
- Git 功能依赖外部 Git for Windows。
- 设置中的「文件树自动定位」「Git 组」「单实例」开关尚未接入运行时（单实例固定开启）；
  Git 组对应行为请在 Git 界面手动切换。
- 「重新解释」编码不可用，只能「转换并保存」。
- 冲突解决的手动整篇编辑仅支持 ≤512KB 的文件，更大的文件只能逐块选择。
- 无终端 / 调试器 / 测试运行器、无 AI 补全、无插件系统。
- 便携版的跳转列表、任务栏进度、系统通知尚未实机验证（需确认）。
