### 关键技术判断（后续实现必须遵守）
1. 编辑器内核 CodeMirror 6，不用 Monaco：Monaco 体积是 CM6 的 15 倍以上，且视觉/交互 DNA 是 VSCode，贴 JetBrains 要持续对抗默认值。
2. **Git Diff 不用 `@codemirror/merge` 渲染**：CM6 merge 自算 chunk 边界，与 `git diff` hunk 不一致会导致"暂存这一块"暂存错内容（数据正确性问题）。改为 `air-git` 解析 git 原生 diff → 自建只读 CM6 渲染层 + block widget 按钮，hunk 操作靠重拼 patch + `git apply --cached`。
3. LSP 必须做 **LanguageServerPool**：`@codemirror/lsp-client` 一个实例只能连一个 server（作者 2026-07 确认），多语言项目按语言分实例。
4. Git 全部走 CLI（含读操作），理由 hooks/GPG/credential helper/CRLF filter；status 用 `--porcelain=v2 -z --branch`，commit message 走 `-F -` stdin（Windows 中文/多行安全）。
5. PHP 语言服务器首选 **PHPantom**（Rust，~2s 就绪，MIT，Laravel 友好），phpactor 兜底（全量索引约 1.5 分钟，体验差）。
